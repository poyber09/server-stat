# server-stat
i'm just trying to learn some linux and its my first real practice from [Roadmap.sh Projects](https://roadmap.sh/projects/server-stats) :)

## Features
- CPU usage: Displays total CPU usage as a percentage.
- Memory Usage: Shows total, used, and free memory.
- Disk Usage: Displays disk space usage across filesystems.
- Top 5 CPU Processes: Lists the five processes using the most CPU.
- Top 5 Memory Processes: Lists the five processes using the most memory.
